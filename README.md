# SpendWise AI · 帮你省

帮助用户省钱消费的 AI agent 应用。

## 产品定位

SpendWise AI 是用户的智能消费助手：围绕真实需求和预算，帮助用户判断是否值得买、比较可选方案，并找到更划算的购买方式。

## 产品目标

- 降低消费成本：比较商品、服务与购买渠道的实际到手价。
- 减少决策负担：将价格、优惠条件与产品差异整理为可理解的建议。
- 避免不必要的消费：优先考虑用户需求与预算，不以促成购买为目标。
- 建立长期信任：清楚说明信息来源、价格时效、推荐理由及商业利益关系。

## 初期探索方向

以下为待验证的产品方向，并非已经实现的功能：

1. 需求理解：通过对话明确购买目的、预算和偏好。
2. 方案比较：比较商品价格、运费、优惠门槛及售后条件。
3. 消费建议：给出购买、等待降价或暂不购买的建议及依据。
4. 降价提醒：在用户授权后跟踪关注商品的价格变化。

## 产品原则

- 以用户实际节省和需求满足为核心，不鼓励为优惠而购买。
- 不编造价格、优惠或可用库存；无法核实时明确说明。
- 区分预计节省与实际节省，并说明比较基准。
- 涉及下单、付款或订阅等操作前取得用户明确授权。
- 仅收集完成任务所需的信息，并提供清晰的用户控制。
